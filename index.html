Settings

Primary full backup: notes, reminders and every photo/video go to a “Notes Backup” folder in YOUR OWN Google Drive as one ZIP. The app's Client ID is configured once in config.js (public by design, it is not a secret and never per visitor) — so nobody pastes anything here. Connecting opens Google's window once for the current user to choose their account; the app never sees a password and gets only a short-lived ticket that is forgotten when you close the page and can only touch files this app created in your Drive. Disconnect forgets this browser's sign-in only. No GitHub token, PC or watcher is needed for this backup.

Optional PC relay (legacy): a one-time github.com → Settings → Developer settings → Fine-grained tokens → Generate new token: Repository access “Only select repositories” → choochatgpt/ask-ai-relay → Permissions → Contents: Read and write. The token lives only in this browser and is never placed in the app's public code. This relay is NOT needed for the Google Drive backup above — it only adds the old PC copy (a folder plus an emailed CSV) when the optional watcher is running.

Export CSV

Emergency text backup: Export CSV opens your mail app with the whole backup in the message body. Photos and videos ride along only in the two backups above.

Paste the whole backup CSV from your email, then preview it before restoring.
